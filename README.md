# Lerndashboard

**Eine einfache und übersichtliche Web-App zur Verwaltung digitaler Lernressourcen für Schulen in Mecklenburg-Vorpommern.**

## Über das Projekt

Lerndashboard ist eine **Progressive Web App (PWA)**, mit der Schulen in MV ihre genutzten digitalen Tools, Plattformen und Ressourcen zentral erfassen, verwalten und übersichtlich darstellen können.

Die App ist bewusst leichtgewichtig, statisch und ohne Backend konzipiert – sie läuft komplett im Browser und kann sehr einfach selbst gehostet werden.

## Features

- Übersichtliche Liste aller digitalen Ressourcen
- Einfaches Hinzufügen, Bearbeiten und Löschen von Einträgen
- Suche und Filterfunktion
- Installierbar als Progressive Web App (PWA) auf Handy, Tablet und Desktop
- Vollständig offline-fähig dank Service Worker
- Optimiert für den Einsatz an Schulen in Mecklenburg-Vorpommern

## So wird die App genutzt

1. Die App über einen Browser öffnen (z. B. über GitHub Pages oder einen eigenen Webserver)
2. Auf „Installieren“ klicken (oder über das Browser-Menü → „App installieren“)
3. Fertig! Die App steht dann wie eine native App auf dem Homescreen zur Verfügung.

## Installation / Hosting

**Einfachste Variante:**
- Die App über [GitHub Pages](https://matthiasklossmpz.github.io/lerndashboard) nutzen
- Oder den gesamten Ordner auf einen beliebigen Webserver kopieren

**Lokale Entwicklung:**
```bash
# Repository klonen
git clone https://github.com/MatthiasKlossMPZ/lerndashboard.git

# In den Ordner wechseln und Start-Skript ausführen
cd lerndashboard
./Start.sh
```
